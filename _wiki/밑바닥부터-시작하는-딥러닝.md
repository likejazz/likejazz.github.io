- p263 RoPE는 회전 행렬을 사용해 상대 위치 정보를 어텐션에 반영하므로 Positional Encoding/Embedding을 사용하지 않고 어텐션에 직접 주입한다.

RoPE는 (Q, K에만 적용) max_context_leng의 arange에서 각 attention head 크기 1/2 만큼 angles값을 먼저 만들어 낸다. 당연히 최초 한 번만 만들 수 있음 (캐시로 저장)

```python
# angles
tensor([[   0.0000,    0.0000,    0.0000,    0.0000],
        [   1.0000,    0.1000,    0.0100,    0.0010],
        [   2.0000,    0.2000,    0.0200,    0.0020],
        ...,
        [1021.0000,  102.1000,   10.2100,    1.0210],
        [1022.0000,  102.2000,   10.2200,    1.0220],
        [1023.0000,  102.3000,   10.2300,    1.0230]])

cos = torch.cos(angles)
sin = torch.sin(angles)

>>> cos
tensor([[ 1.0000,  1.0000,  1.0000,  1.0000],
        [ 0.5403,  0.9950,  0.9999,  1.0000],
        [-0.4161,  0.9801,  0.9998,  1.0000],
        ...,
        [-0.9998,  0.0018, -0.7072,  0.5225],
        [-0.5550, -0.0981, -0.7001,  0.5217],
        [ 0.4001, -0.1969, -0.6930,  0.5208]])
```

회전 적용:
```python
x_rot_even = x_even * cos - x_odd * sin
x_rot_odd  = x_even * sin + x_odd * cos
```

이후 원래 순서로 복원:
```python
out = torch.stack([x_rot_even, x_rot_odd], dim=-1)
out = out.reshape(batch_size, num_head, context_len, key_dim)
```
